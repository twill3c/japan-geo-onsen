# AI の事前登録(loop_013 / 設計書 Phase 4〜5)

**このファイルは、モデルを 1 つも学習させる前に書いて積んだ。** 合否の基準を結果を見てから
動かさないためである。結果の JSON(`public/data/ai/baselines.json`)は、このファイルの

## 1. 何を当てるのか(ラベルの意味)

設計書 §33 は「`hot_spring_exists = 0` を温泉が存在しないと解釈しない」と定めている。
しかも、地点ごとの**泉温・湧出量・泉質の公開データは無い**ので、それらを当てる回帰や分類は立たない。

そこで当てる問いを次のように定める。

> **観光資源データ(国土数値情報 P12)に登録された地点のうち、その地点が「温泉」の分類で
> 登録されているか、それとも温泉以外の観光資源か。**

- 正例(1): P12 の温泉 1,320 点(`onsen.geojson`)
- 負例(0): P12 の温泉以外の観光資源から、**都道府県ごとに同じ数**を無作為に選んだ 1,320 点(`control.geojson`)

負例は「温泉が無い場所」ではない。「人が観光資源として登録した、温泉以外の場所」である。
だからこのモデルが学ぶのは **「温泉として登録された場所の地理環境の傾向」** であって、
**温泉が湧くかどうかではない**。画面にもそう書く。

## 2. 使う特徴量

地点ごとに既に付けてある実データだけを使う。

| 種類 | 特徴量 |
|---|---|
| 地形 | 標高 `elevation_m`・傾斜 `slope_deg`・局所起伏 `local_relief_m` |
| 地質 | 地質の大区分 `geology_group`(カテゴリ) |
| 火山 | 最寄りの活火山までの距離 `distance_to_volcano_km` |
| 水 | 最寄りの河川までの距離 `distance_to_river_km`・最寄りの湖沼までの距離 `distance_to_lake_km` |
| 植生 | 植生自然度 `vegetation_naturalness`(1〜10 を数として。98/99/00 は欠測扱い) |

**使わないもの(漏れ)**: 名前に「温泉」「湯」を含むか・出所・分類コード・種別名称・ID・住所・
都道府県・周辺の温泉の数(正例にしか計算していない)。これらはラベルそのものか、
ラベルの作り方を映すだけである。

**無いもの**: 設計書 §52 の「断層」は取り込んでいない。泉温・湧出量・泉質は公開データが無い。

欠測は、**学習に使う側の分割の中だけで**中央値で埋め、欠測したことを示す列を足す。

## 3. 評価の仕方

- **検証は都道府県ごとの分割(GroupKFold, 5 分割)**。近くの温泉が学習と検証の両方に入ると、
  場所を覚えただけで当たったように見える(空間の漏れ)。都道府県を丸ごと検証側に回す
- 比べるための参考として、**無作為な 5 分割**の数も並べる(漏れの大きさを見せるため。合否には使わない)
- 指標(設計書 §31): Accuracy・Precision・Recall・F1(しきい値 0.5)・ROC-AUC・PR-AUC。
  すべて分割の外側の予測(out-of-fold)で計算する
- モデル(設計書 §53): Logistic Regression・Random Forest・XGBoost
- 乱数の種は 20260915 に固定する

## 4. 比べる相手(ベースライン)

1. **定数の予測**(ROC-AUC 0.5)
2. **特徴量 1 つだけのロジスティック回帰**を 7 つの数値特徴量それぞれで作り、
   都道府県分割の ROC-AUC がいちばん高いもの(= いちばん強い 1 変数)

## 5. 合否(ここを結果を見てから動かさない)

| ID | 条件 | 意味 |
|---|---|---|
| G-22a | 3 モデルのうち最良の都道府県分割 ROC-AUC が **0.65 以上** | 偶然よりはっきり当たる |
| G-22b | 最良モデルの都道府県分割 ROC-AUC が、**最強の 1 変数ベースラインより 0.02 以上高い** | 組み合わせる意味がある |
| G-22c | 陰性対照: 都道府県の中でラベルを無作為に入れ替えて学習し直すと、最良モデルの ROC-AUC が **0.45〜0.55** に収まる | 仕組みがラベルを漏らしていない |

- G-22c が落ちたら、**他の数字は信じない**(漏れを疑って直す)
- G-22b が落ちたら、「組み合わせても 1 変数より良くならなかった」と**そのまま出す**。
  閾値を下げない・特徴量を足して取り直さない(足すなら別の事前登録として書き直す)
